# React + Vite
# 前端部分

#### 介绍
一个算法平台的前端，使用ant-design作为模板

#### 软件架构
基于 Vite 构建工具链进行架构设计，以 React 作为核心前端库，JavaScript 为实现语言，并集成了 Ant Design 组件库，打造精致的 UI 框架。


#### 安装教程
无

#### 使用说明

下载到仓库后，还要引用相关的包
React项目
```JavaScript
npm install antd --save  # 安装 Ant Design 组件库
npm install @ant-design/icons --save  # 安装 Ant Design 图标库
```
